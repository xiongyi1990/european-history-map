# 古希腊伴读样本

适用：配合《企鹅欧洲史》第一卷与顾衡欧洲史专栏，先解决地点定位、空间比较和开战时的阵营辨识。

## 两种入口

- `blender/greek-reading-atlas.blend`：Blender 5.2.1 LTS 制作的可编辑立体沙盘。双击打开后可旋转、缩放；小键盘 0 切换相机视角，F12 重新渲染。中文字体已打包。
- `blender/greek-reading-atlas.png`：已渲染的预览图，适合直接查看。
- 网页：在本目录运行 `npm run dev -- --port 5180 --strictPort`，打开 http://127.0.0.1:5180/?atlas=greece 。旧版保留在 `/legacy`，旧版的跨年代边界选择机制不作为新样本的数据依据。

网页收录 26 个地点，支持古今地名和别名检索、来源详情、3D 地形、现代国界对照、两地距离与位置比较、本地阅读书签。3 个阅读引导是同一历史时点的不同观察方式，不是 3 个年代。书签保存在当前浏览器，包含地点、视角、图层和阅读步骤；两地临时比较不保存在书签里。

## 战役路线（网页版）

点击右上角“战役路线”，或直接打开 http://127.0.0.1:5180/?atlas=greece&battle=marathon&stage=0 。已加入 4 个专题、15 个阶段：马拉松（前 490 年）、温泉关（前 480 年）、萨拉米斯（前 480 年）、西西里远征（前 415—413 年）。

底部编号或左右按钮切换阶段；播放按钮每 6.5 秒推进一页，可暂停，最后一页自动停止。“定位本阶段”放大当前路线，右上定位按钮恢复整场范围。粗线与箭头代表当前行动，淡线代表此前阶段。播放速度不表示历史时间比例。

每一阶段附原典章节链接。线路和编号点是编者根据叙述绘制的近似地理示意；中间折点不是已核实的经停点。温泉关不重建古海岸与精确山道，萨拉米斯不复原有争议的舰队阵形，西西里远征省略部分往返与停靠，末页仅标结局地点。

战役模式使用自己的年份与行动方说明，不显示前 431 年阵营。战役书签与原城邦书签分开保存；网址保留战役和阶段，可复制后在本机重新打开。Blender 沙盘仍是前 431 年地理版本，本次战役交互在网页中使用。

路线数据：`src/greek/battles.ts`。资料主要来自希罗多德《历史》第六至八卷及修昔底德《伯罗奔尼撒战争史》第六、七卷；各阶段列出具体章节。四个专题为阅读摘要，尚不是古希腊主要战役的完整目录。

## 已核实和未完成的边界

### 立体地貌新版

网页现在默认打开立体视角。采用真实现代高程的分层设色：深蓝至浅青为水深，浅绿低地逐渐过渡到褐色山地与浅色高山。颜色表达高程，不代表真实植被、积雪或古代土地利用。网页高度放大 4 倍；“切回俯视”保留设色与山体阴影。

左下角“山脉／平原／海洋”可以靠近观察具体地貌；地貌标签可点击，附资料链接。山名、平原与海域标签为近似代表位置，不是地貌范围边界。路线的阶段、播放与原典链接保持可用。

现代高程缓存扩展到第 9 级：763 张保留海底负高程的原始图块用于水深与海拔设色，另 763 张海底归零图块用于立体地形。区域内陆海分色沿现代高程的零值附近变化，是近似地形参考，不是测绘海岸线；区域外使用 Natural Earth 后备底图。再生成：`python scripts/prepare-greek-surface.py`。

- 城邦模式的历史场景固定为公元前 431 年开战之初，政治关系不外推到全年、其他年代或战役模式。
- 地点来自 Pleiades 的代表点。原记录的 precise / rough 分类被保留；即使是 precise，也不是对公元前 431 年城墙或城市中心的单独测绘。西库昂等跨时期位置需要特别留意。
- 同盟连线仅连接部分收录的独立城邦和阵营领导者，表示关系，不是领土、军队行进或航线。港口、雅典辖下聚落与圣地不作为独立盟邦画连线。
- 尚未录入通过核对的公元前 431 年城邦领土多边形；地图没有用其他年份的边界替代。地图“领土资料”与地点详情明确说明该缺口。
- 居民页面仅展示可以支持的说明，不提供族群比例，也不把语言、文化身份、公民身份和阵营混为一谈。
- 3D 是现代高程参考；网页高度放大 4 倍，Blender 放大 6 倍以便观察。立体海平面以下地形归零，原始负高程仅用于水深颜色。
- 网页区域内沿高程设色显示陆海，Natural Earth 1:50m 作为区域外底图与现代国界；Blender 从高程生成陆地。二者均不代表古代海岸，米利都、以弗所等港口环境尤其需要后续独立重建。
- Blender 范围为 20.1–28.8°E、35.6–40.8°N，覆盖网页地点中的 24 处，科西拉和叙拉古不在沙盘裁切范围内。模型中的标注引线只关联地名与其代表点。
- 尚未建立两套读物逐章、逐讲对应关系。

## 资料来源

1. Pleiades contributors，CC BY 3.0；2026-09-07 从官方 GIS 下载导出 26 条记录。每条记录保留原始页面链接、代表点、精度与出处。见 https://pleiades.stoa.org/downloads 与 https://atlantides.org/downloads/pleiades/gis/ 。数据文件：`src/greek/pleiades.json`。
2. 修昔底德《伯罗奔尼撒战争史》第二卷：2.2–6 普拉提亚事件，2.9 双方盟友，2.13–17 雅典准备与阿提卡。Richard Crawley 英译，MIT Internet Classics Archive：https://classics.mit.edu/Thucydides/pelopwar.2.second.html 。地点页面区分逐城点名与地域性推定，具体状态仍可进一步交叉核查。
3. Mapzen / AWS Open Data Terrarium 高程：https://registry.opendata.aws/terrain-tiles/ 。立体地形缓存位于 `public/greek-terrain`，共 763 张；原始陆海高程位于 `public/greek-surface`，另 763 张，附 manifest.json。各原始高程数据集许可与署名以 AWS 项目所指的来源清单为准：https://github.com/tilezen/joerd/blob/master/docs/attribution.md 。本地处理仅将立体用的海面以下值设为 0，不做古代地貌推定。
4. Natural Earth 公共领域陆地与现代边界，经 world-atlas 数据包提供：https://www.naturalearthdata.com/about/terms-of-use/ 。

## 再生成与验证

网页：`npm ci`、`npm test`、`npm run build`。

数据脚本：`scripts/prepare-greek-places.py` 提取有署名的地点；`scripts/prepare-greek-terrain.py` 缓存高程；`scripts/prepare-blender-heightmap.py` 生成区域高程网格；`scripts/build-greek-blender.py` 在 Blender 后台生成模型和预览。普通 Python 的地形处理使用 Pillow 与 NumPy。

测试覆盖古今别名对应、地点范围、阵营分类中的反例、大圆距离、原有日期与历史图层工具，以及战役分步显示、链接阶段校正、播放停止和书签隔离。浏览器检查包括地形切换、别名检索、详情、两地比较、古今对照、资料弹窗和书签恢复。

下一轮优先：补齐雅典与斯巴达领土的可追溯重建依据，再增加第二个时间点；不要以地名点或后世边界直接生成古代领土。
