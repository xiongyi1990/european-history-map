# 1360—1453：四处意大利城市政权

在27个既有明确时点补米兰、佛罗伦萨、威尼斯与热那亚四个固定阅读核心，阶段共37地域。新增8个古今地点，复用米兰、帕维亚、佛罗伦萨、比萨、威尼斯和原有维罗纳；352条单年城市/事件资料取代原循环中的比萨1409、佛罗伦萨1439两条泛化焦点，净增350。记录数不表示352次独立人口调查或年度实控地图。

## 政治与城市时间线

- 米兰1360年代有贝尔纳博、加莱亚佐二世不同支系；1378父系继承、1385政变、1395/1396授封分开。授封者瓦茨拉夫是罗马人的国王，未获帝冠。所谓1397“伦巴第公国”文书为伪，不加入新称号。
- 1402乔瓦尼·玛丽亚继米兰公爵、腓力另为帕维亚伯爵。1409保留地方军政影响未逐月复原，1410法奇诺实际掌握帕维亚；不能以伯爵头衔盖过实控。1447—1450安布罗西亚共和国与1450斯福尔扎取得城市，不压成连续王朝继承。
- 佛罗伦萨是共和国。1378夏季梳毛工短暂执政在8月末结束；年底不能仍列米凯莱为现任旗手。1381反攻与放逐、1382寡头全面复归分期。1434以后科西莫的实际优势不等于公国，也不等于他每个年底都任旗手。
- 比萨1405权利出售、1406实际攻取和里窝那1421购买不同步。卢卡1360/1364仍在比萨控制背景，1369自由、1400—1430圭尼吉领主、1430恢复共和单列，不因邻近佛罗伦萨而自动归属。
- 威尼斯总督是受制度约束的共和国首席政务官。1381特雷维索转出与1388年底回归、1404维琴察、1405维罗纳/帕多瓦、1426布雷西亚及1428和约分别理解。1439维罗纳短暂被占后夺回；布雷西亚被围不是失守。1409达尔马提亚权利交易也不证明全部港口当天交付。
- 热那亚有共和总督、法王/蒙费拉托侯/米兰公爵的外来领主阶段。1435年末取12月27日临时八位自由队长政府，不能提前填1436托马索复位。1453圣乔治之家取得外海权利与本城政府分层；君士坦丁堡陷落不表示热那亚或威尼斯本土灭亡。

## 几何、地名与精度

四块新几何为原创编辑坐标，经公有领域Natural Earth现代陆地裁切，不是历史地图描摹。原italy核心仅在1360—1453的27个时点减去新核心，余区改称“其他城市与教会权利”；以前包含的陆地仍由新核心或余区覆盖。此前1513个其他几何记录内容保持不变，27个意大利余区重新划分，新增108个核心，合计1648。

米兰与帕维亚、佛罗伦萨与普拉托、热那亚、威尼斯附近帕多瓦落入相应阅读核心。帕多瓦在1405以前虽位于同一地理核心，城市卡仍显示不同治理，色块不能推导附属关系。威尼斯潟湖岛屿在Natural Earth50m中有缺失，原威尼斯代表点不挪动，几何检查允许小于0.10度的陆地偏移；不是城市界线精度。维罗纳、布雷西亚、比萨、卢卡、里窝那及安吉亚里为新核心以外比较点。

没有画米兰最大主张、威尼斯完整陆地/海外领地、热那亚科西嘉/黑海据点或全部托斯卡纳。现代点位不复原当时港口岸线、城墙、战场阵形与会场。也没有复制邻年疆界并宣称完成逐年控制图。

## 居民、书写与史料层次

1427税籍只能在其后时点作为已出现档案；它记录家户与财产，不是祖源/母语普查。1382—1410达蒂尼书信有私人、商业及织物样本，已刊语料库与完整档案分开；1410以后引用的是旧档案，不让本人继续在世。1414—1416布雷西亚账簿涉及乡村城堡经营，不代表全城人口调查。

威尼斯德意志商馆经纪人需要读说德语，说明跨语交易，不证明全城双语比例或外国领土。1382总督誓约是制度材料，不当普通居民口语。基纳佐编年史的特雷维索方言和1439存世抄本分别看，不将后者倒填1378。米兰、热那亚本阶段同期原始语言样本不足，保留缺口，不给全城填一种母语。
