# 1002—1100年：帝国与教皇

新增十个明确节点：1002、1014、1024、1027、1032、1034、1056、1077、1084、1100。复用命名地域的阅读包络，各时点的统治者、王号/帝号、继承和地方权利独立核验。它们不表示100年间疆界未变，也不是全欧洲逐年政权清单。

## 年代与适用时点

- 1002年末：亨利二世在北侧取得王位；意大利阿尔杜因称王，1004年意大利加冕、1014年帝号不提前。
- 1014年罗马加冕后：亨利二世已有帝号；阿尔杜因的退出在1015年，不能提前算作全境平定。
- 1024年康拉德二世当选后：萨利安王朝开始；1026年意大利王号、1027年帝号在以后。
- 1032年鲁道夫三世去世后：勃艮第处于继承争夺；1033年加冕、1034年进一步军事整合分开，本卡保留单独争夺颜色。
- 1056年亨利三世去世后：幼年亨利四世与阿格尼丝等摄政治理，不能继承父亲帝号。勃艮第同色表示王权联系，并非统一直辖。
- 1077年1月解除绝罚后、3月对立国王选举前：本卡不是1077年全年状态；亨利仍是国王。玛蒂尔达的卡诺莎城堡不当作他的直辖首都。
- 1084年3月罗马加冕后：亨利由他支持的克雷芒三世加冕，格列高利七世一方仍在。
- 1100年：亨利四世的帝号与亨利五世的共同王位并存；不提前套用后来的父子反叛结果。

## 空间与验证边界

五块阅读地域：法兰西、德意志方向、洛林、勃艮第、北中部意大利。后两者的政治关系、教皇与玛蒂尔达的权力均在卡中解释；色块不复原战争阵线，也未绘精确旅行路线。

卡诺莎为近似遗址定位，1077年城市详情仅适用于本年；即使在意大利阅读包络内，地图也不把该点着为国王直接领地。分享保留年份和地域，城市返回及阶段切换均有回归验证。1000年的六方向比较不借用到11世纪。

另补1027年罗马加冕与1034年日内瓦效忠之后的时点，使王位—帝号、继承争夺—共同王权两个转变可以前后对照。
