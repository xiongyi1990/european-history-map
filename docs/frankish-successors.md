# 900—1000 年：法兰克继承诸国

原843—880年专题之后，目前有900、911、919、925、936、951、955、962、965、973、983、987、996、1000共14个**地域与王权关系**节点，不代表已经完成这一世纪的全部欧洲疆界、地方政权或居民资料。

## 阅读顺序

- `?year=900&view=partitions`：东西部、意大利、洛塔林吉亚与上下勃艮第；分清童子路易和普罗旺斯的路易。
- `?year=911&view=partitions&kingdom=lotharingia`：取年末，洛塔林吉亚联系西部查理三世，东部另选康拉德一世。
- `?year=925&view=partitions&kingdom=lotharingia`：转向东部亨利一世；南部鲁道夫二世同时涉足上勃艮第与意大利。
- `?year=962&view=partitions`：936王位、951意大利王号与962帝号分开；勃艮第不并入。
- `?year=987&view=partitions`：于格·卡佩即位与王室领地区别；奥托三世尚无帝号。
- `?year=1000&view=partitions`：奥托三世、罗贝尔二世、鲁道夫三世分别定位；格涅兹诺、埃斯泰尔戈姆为外部比较点。

阶段按钮连接843—880与900—1000。关系卡、色块、搜索均能打开地域组成；分享链接保留年份、地域及城市，城市详情可返回。950、963等未核地图年不会套用邻近关系色块；已有通用事件说明继续可用。

## 课程核验

原PDF为用户提供的《顾衡讲透欧洲史（不含加餐）》，页码从PDF第一页计。本批不复制课程全文或图片。

- 第144讲1213—1215页：诺曼底、东西法兰克、卡佩与奥托。继承叙述有简化，需与159讲并读。
- 第159讲1350—1352页：诸公国、康拉德、亨利、奥托与帝号。
- **1351页图题是约1000年，但图例同时显示972年奥托一世与1032年康拉德二世两组范围。**不能把1032年线所涉勃艮第提前画入962或1000年的帝国。
- 第175讲1489—1490页：王国、诸侯与王室领地的制度背景。1491页的图是12—14世纪初年的法兰西，不能当987年的边界图。
- 911/925的洛塔林吉亚归属、951意大利王号及勃艮第整合细节采用外部补充资料，不据课程文字检索结果声称每一讲或图片均已覆盖。

## 来源与历史关系

每个节点在展开来源中列出核验URL，源表见 `src/europe/frankish-successors.ts`。

- LVR莱茵地区历史门户与博帕德博物馆：洛塔林吉亚的东西部关系、公爵与教会权力。
- 德国传记（NDB/ADB）与Treccani传记辞典：童子路易、普罗旺斯路易、奥托一世及意大利王位。900取年末；900年不写路易已有901年的帝号。
- 瑞士历史辞典与NDB鲁道夫家族条目：上勃艮第、罗讷河王权及渐次整合，不把常见的933概括写成当日所有地方已统一实控。962/987康拉德在位，1000鲁道夫三世在位。
- 大都会博物馆、LVR与钱币/文书资料：奥托王朝，尤其987王位与996帝号的区别。
- 法国国家图书馆、CNRS印章资料与菲茨威廉博物馆：西部君主及年代。王国与王室自有领地不等同。

政治名称、地方语言与居民身份分别说明；没有族群比例证据时不补造。世系、王冠、外交、保护或朝贡都不直接折算为完整的直接控制面积。

## 几何与覆盖边界

`scripts/build-frankish-successors.py` 生成33个带 `spatialScope: regional-context` 的原创概略地域多边形，使用Natural Earth公有领域现代陆地裁切。固定包络用于相互定位，**不声称900—1000年实际边界保持不变**。控制变化通过同色关系和文字呈现；具体每年的城镇控制、边疆和内部领地还需继续补。

本图将洛塔林吉亚从原北方走廊中单列，将汝拉/日内瓦湖方向分给上勃艮第；后段合为勃艮第王国阅读区域。第戎方向仍属于西部，不能与同名王国混淆。意大利采用北中部阅读核心，罗马、威尼斯、拉文纳、南部没有被画成统一直辖。东部保守显示核心；波希米亚、东部边疆与周边诸国关系未全部画出，留白不是无主。上下洛林内部界线尚未细画。周边不列颠、伊比利亚、北欧、东欧与东罗马仍在欧洲概览及既有资料中，本专题并非整个欧洲的替代图。

王国组成卡列出的地域可能比概略色块更广，包络不用于面积计算。城市链接包含邻国比较，只有单独核定的地域归属才赋色；罗马、格涅兹诺与埃斯泰尔戈姆不因有链接而加入意大利或东部王国。

## 验证

生成脚本检查有效、非空、同年不重叠，以及巴黎、第戎、亚琛、雷根斯堡、马格德堡、帕维亚、里昂、阿尔勒、日内瓦、巴塞尔的代表位置；排除罗马、布拉格、格涅兹诺、埃斯泰尔戈姆、威尼斯、拉文纳。

Vitest检查事件年与几何一一对应、城市ID存在、比较点不误赋色、911/925联系变化、失效王国ID清理、分享链接与城市返回，以及旧843—880专题保持可用。构建与浏览器检查结果以本次发布记录为准。


## 关键年份加密：八个明确时点

| 年份 | 具体状态 | 需要分清的层次 |
|---|---|---|
| 919 | 亨利一世当选后；洛塔林吉亚仍联系西部 | 选王与925年转归不同 |
| 936 | 奥托一世、路易四世即位后 | 王位不是帝位；勃艮第整合未抹平地方差别 |
| 951 | 帕维亚行动和阿德莱德婚姻后 | 意大利王号、952年安排、962年帝号不同 |
| 955 | 8月奥格斯堡附近战后 | 王权威望、意大利从属安排、匈牙利盆地不被混成吞并 |
| 965 | 取年末，布鲁诺去世后 | 父亲是皇帝、儿子为共同国王；967年帝号与968年大主教区不提前 |
| 973 | 5月奥托一世去世后 | 奥托二世已有967年共同帝号，本年承接单独统治 |
| 983 | 年末，奥托二世去世、幼王在亚琛加冕后 | 不能把随后稳定摄政安排提前；东部边疆反叛另说明 |
| 996 | 年末，罗马加冕及于格·卡佩去世后 | 奥托三世帝号、西部罗贝尔二世单独统治、独立勃艮第分开 |

这些是逐个核验的政治关系节点，不插值生成未核年份。边界仍是固定阅读地域包络，936年保留上下勃艮第两块用于表达整合中的权利，951年起的合并阅读包络也不声称由某一年同时控制所有地方。

加入955年奥格斯堡参照城市和仅适用于955年的城市详情；坐标为城市中心近似定位，不是精确战场。地区官方资料明确指出精确会战位置仍未知，因此没有虚构路线或阵地。

地图上的快捷年代改为前一节点、带标题的年份选择、后一节点；侧栏列出全部14年。原有本年事件仍可展开，例如965年马格德堡文书、973年埃及宫廷迁移，避免政权图导览遮蔽同年资料。
