# 1190—1282：诸王国、继承与地域

本批28个明确时点，从巴巴罗萨去世延伸到西西里晚祷后的岛屿—大陆分治。新增英格兰与西西里王国阅读地域，1282年另外分出南部大陆。它们是编辑性地理包络，经现代陆地裁切；不是逐年实控国界。

## 时间与身份核验

- 亨利六世1190年为王，1191年获帝号，1194年战争后在巴勒莫加冕为西西里国王。
- 1197年继承过渡、1198年腓力与奥托双重选王分开；幼年腓特烈的西西里王权并非帝号。
- 1204年诺曼底征服、1214年布汶会战分开；约翰的南方行动不等于他本人在布汶北方会战。
- 1212年美因茨王号、1215年亚琛再次加冕、1220年罗马帝号分开。1215年取7月底时点，明确在宪章8月废止以前，不声称全年和解。
- 1220年南北共享君主，但制度上不把西西里合为帝国普通行政区。幼子亨利的王号与腓特烈本人分层。
- 1231年梅尔菲法典针对西西里王国，不自动适用于帝国全境。1235年亨利失势、1237年康拉德选王和科尔泰诺瓦会战分开。
- 1245年教皇宣告废黜与皇帝实际继续抵抗分开。1250年皇帝死亡不等于没有国王，1254年康拉德死亡又是下一节点。
- 1266年贝内文托、1268年塔利亚科佐战役与那不勒斯处刑分开。1273年鲁道夫为王而非获帝号。
- 1282年取9月后：佩德罗在岛上、查理保有大陆，战争继续。不是查理失去所有领地。

## 读图与尚存范围

英格兰包络限制在大不列颠岛相应核心，卡迪夫和爱丁堡不包含其中。西西里王国在1282年前是岛屿与南部大陆一起读，1282年拆开。南部包络覆盖塔利亚科佐战役地域但不包含罗马。每年检查几何有效性、非重叠与代表地点。

新增墨西拿、梅尔菲、塔利亚科佐、布汶、兰尼米德、科尔泰诺瓦6个近似地点；不把现代纪念碑或城镇坐标称为精确战场。补充125条单年城市政治说明。城市事实和政治读图能力有实质增加，但它们不是125份全城市社会史，也不构成28年全欧洲疆界完成证明。人口比例、语言边界以及北欧、东欧、伊比利亚与东地中海的同期完整图层仍需继续审核。
