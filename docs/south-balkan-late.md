# 摩里亚与瓦拉几亚：1360—1453地方权力

本批在27个既有明确时点补2处阅读核心、9个地点和243条城市／事件卡；不是新增27张精确疆界，也没有把未设置的整数年冒充已完成。全部审核继续为partial。

`south-balkan-late-states.json`按各节点实际月末／年末写王公、地方德斯波特、争位和城市事件；`south-balkan-late-places.ts`将现代定位、居民证据、文本语种及事件地点分开。243条中包括港口背景和明确未核驻军的条目，记录数不表示243次实控验收完成。

## 空间与操作

- 米斯特拉核心只示意泰格特山以东的部分拉科尼亚。科林斯卫城、六英里长墙、帕特雷、莫东和科龙是块外比较点。长墙只设遗址代表点，没有复原墙线、军队路线或阵线。
- 瓦拉几亚核心定位阿尔杰什—特尔戈维什泰；久尔久岛堡另读。多布罗加、特兰西瓦尼亚、摩尔达维亚、塞韦林和西部边区都不按扩展头衔自动填入。
- `build-frankish-successors.py`用原创坐标和Natural Earth50m现代陆地裁切，前1729个记录逐项不变，增加54个几何。现代陆地裁切不是中世纪海岸复原。核心之间不重叠，代表点包含／比较点排除均有断言。
- 城市返回保留地域选择；只把米斯特拉、阿尔杰什和特尔戈维什泰直接联系到相应核心，港口、长墙和城堡不因链接而自动归属。

## 核验与来源边界

完整链接集中在`src/europe/south-balkan-late-sources.ts`。已直接阅读的独立证据包括：

1. 希腊文化部米斯特拉、UNESCO申报页及ICOMOS评估物理2页：地方省级治理、城市结构、1402交易取消、1446纳贡与1460终点。文化部“1432收复全半岛”概括不用于吞掉威尼斯港口；1448继位叙事与1449年1月6日加冕分开。
2. Barker学术年表物理4页：1381马修临时治理、1382塞奥多罗斯启程、1384确立。Speculum2022印1107—1109页：1427—1429不同宫廷与兄弟分区。没有由此推导全部乡村辖界。
3. ASCSA《Corinth III.2》物理153—158／印140—145页：1358转让、1395转归、1400春骑士团持堡、1404年5月5日回购及1415／1423／1444／1446／1452／1458时序。科林斯市政网页记1397，与1400记年并列；1397／1399保留过渡，不猜驻军。古书的贬义族群叙述和人口估计未采用。
4. 帕特雷官方考古PDF物理3—4页：1408五年租约、1417两年租约、1427周围领地、1429城镇与1430年5月城堡不同交接。没有把租约无限延伸或把城镇等同山顶城堡。
5. 麦西尼亚考古署及文化部莫东／科龙页面：本阶段威尼斯港口、1500未来征服。国家希腊研究基金会纹章目录区分1406—1407和1497—1499的实物，不能整组倒填1409。欧洲委员会罗姆史物理7—8页与Garland论文摘要：1381莫东城外见闻、1414—1415讽刺文学只作有限社群证据。
6. DRH B I（1966）原文书校刊物理27—32及251页：任期、王廷落款、贵族／修道院／商人权利与原语／译文分层。Rezachevici2001印73—79、90—96页补年代细部，实际读取的是公开镜像，明确非出版社页面。国家通讯社1396—1397争位叙述只取争位，不采用排印错误和争议战役日期。
7. 特尔戈维什泰王廷博物馆：1396旅行描述、1403首份内部文书，不能写成1403才建城。久尔久国家考古登记：始建不确定、1409文书、1417—1420征服范围、1427夺回，不能据此无限延伸驻军。Deletant1980物理2—4页将罗曼语背景和教会斯拉夫语书写分开。

瓦拉几亚1435／1436末期文书的新研究（Mirea2025）全文未能读取；不作为已读依据，不据摘要强定1435年末唯一君主。1396争位恢复范围、摩里亚兄弟辖区、所有城堡逐年驻军、语言人口分布均仍需后续。

课程206讲实读物理1757、1759—1768；1759—1761作引用，1761提供米斯特拉与斯巴达空间线索。1764“巴尔干已基本拿下”的概括不能替代1453各地实况。课程原PDF及全文没有写入代码或发布包。

## 本批验证
