# 克鲁亚与摩尔达维亚：1360—1453地方权力阅读

2026-11-18续批，沿用27个既有明确时点，增加2处固定阅读核心、7个地点与189条单年城市说明。时点沿用主专题的月份：1385为11月底、1386为3月底、1444为瓦尔纳会战后。没有新增中间年份，也没有将相同包络称为27份年度实控疆界。宽域审核仍为partial。

克鲁亚小块只定位山城附近；都拉斯、斯库台与莱什均为块外比较点。摩尔达维亚只画苏恰瓦—锡雷特—巴亚内陆核心；不包含黑海港口、全部普鲁特河东侧，也不是现代摩尔多瓦共和国的边界。原1783个几何记录逐项保持内容不变，另增54个固定核心记录；现代陆地裁切不代表中世纪海岸。

## 可读的变化

- 都拉斯1368首次转托皮亚，不等于1368—1392连续实控。1376雇佣兵夺城、1378—1380离开、1385战后恢复分别标明；1378/1381精确驻军仍待核。
- 都拉斯1392、莱什1393、斯库台1396进入威尼斯阶段。泽塔家族继承、莱什盟会或克鲁亚更换统治者都不能让三城自动同步改色。
- 克鲁亚1394以后地方代理与奥斯曼宗主权分开；1415重占、1431税册、1438任职、1440转任、1443夺堡是不同事件。1444斯坎德培为盟军首席统帅，不能写成全阿尔巴尼亚国王。
- 1450取10月26日撤围之后；1453保留斯坎德培地方权力、1451加埃塔附庸安排与加泰罗尼亚驻军三层关系，不把驻军淡化成纯纸面同盟，也不把全阿尔巴尼亚变成那不勒斯直辖。
- 摩尔达维亚1360/1364兴起纪年保留争议，彼得·穆沙特编号采用说明而非制造两人。1387臣服礼不倒填1385/1386；1399年末尤加不提前换成1400亚历山德鲁。
- 1435和解、苏恰瓦上位中心及南部兄弟辖区分开；1439大印/小印及分治不能变成两人共同管理每一城。1450博格丹二世、1453亚历山德鲁二世，不提前用1457斯特凡三世。
- 锡雷特1453年9月23日协议约定未来另地臣服礼，并非已经在锡雷特行礼。1421林加拉收益与领地安排也不是她继任整个公国。
