# 1360—1453：低地领主、代理与城市

本轮沿用27个明确时点，新增布拉班特、荷兰/泽兰与埃诺三处固定阅读核心，连同独立的佛兰德构成四处对照。阶段共40块阅读地域。新增12个古今地点，复用布鲁塞尔、布鲁日与根特，加入374条单年城市/事件说明，替代27条较粗的根特说明。没有新增1428等全欧洲时点；仅在已有节点解释此前的转折，不复制邻年地图冒充年度实控。

初学者可从1422或1431进入荷兰/泽兰，再比较埃诺和布拉班特，回答“女伯爵、丈夫、叔父、代理人是不是同一人”。蒙斯与瓦朗谢讷今天分别位于比利时和法国；同属历史埃诺不等于当时已有现代法比国界。Bergen在蒙斯别名中也不能误连挪威卑尔根。

## 政治与时点

- 威廉在荷兰/泽兰称五世、在埃诺称三世；1358起阿尔布雷希特代理，1389才正式继伯爵。1404继承的下一位威廉在荷兰称六世、在埃诺称四世、在巴伐利亚称二世。父子及地方参与治理与正式伯号分开。
- 布拉班特乔安娜与温策尔共同治理，1383后由她继续。1390赠与仍保留用益，不据此称已吞并。林堡1387用益、1396权利与1404过渡不同，未画完整林堡。1404代理、安托万1405安特卫普权利及1406继公爵分开。
- 1415阿金库尔后已是约翰四世；1420年底保公爵头衔但弟弟圣波尔菲利普代理，代理至1421年5月。1422已恢复治理。1429是圣波尔菲利普，1430以后才是善良菲利普。
- 1417杰奎琳继承与叔父多德雷赫特拥戴并存。丈夫布拉班特约翰四世与叔父巴伐利亚约翰三世不同。1420荷兰/泽兰质押不能证明埃诺同步全部移交。1422婚姻争议不能提前写1424汉弗莱远征已发生，更不能称英国占全荷兰。
- 1428年7月3日代尔夫特安排保留杰奎琳女伯爵头衔，菲利普善良代理治理并为继承人；1433年4月12日放弃三伯国才是正式伯号转折。1433许可文书的教学译文不直接等于放弃文书，两类材料分别列源。
- 佛兰德1384继承须保留玛格丽特女伯爵。无畏约翰1404继勃艮第公爵、1405继佛兰德伯号；不是同一日期。1385节点取11月底，不能提前写12月18日图尔奈和平。1439布鲁日已经历1436—1438冲突；1450根特冲突升级，1451公开战争与1453战败另看。

## 文书、居民与语言

1356《欢悦入境》的鲁汶原本校刊及拉丁译文、Damen研究1406/1415召集名单、1367/1389代理及伯爵印章、布鲁日约1400格鲁特胡斯手稿、1436诉求与誓约以及蒙斯1440年代法语史书，分别提供制度、代表身份、书写和文化圈层线索。召集不等于出席，城市特权不等于普选，拉丁印章、现代译文或一个手稿均不是人口口语调查。沃克兰的宫廷叙事也不是全城居民自我认同。早于材料出现的节点不写材料已存在。没有族群比例或完整语言分布层。

## 空间与战事

全部新增几何为原创阅读示意，现代Natural Earth陆地裁切；不是取自同期疆界，也不是逐年实控或现代省界。荷兰本部与米德尔堡附近为两个地理组件，泽兰全部岛屿、围垦和古水道未复原。安特卫普位于布拉班特地理核心内，但早期政治说明仍归佛兰德；色块不证明所有年份同一领主。旧法兰西、佛兰德及洛林阅读区只在1360以后分出重叠部分，早年形状不改；对生成前几何逐项验证。

罗斯贝克点取西罗斯贝克村南古德贝赫方向；1382战败不等于根特立即停止抵抗。1453加弗尔点取瑟默扎克高地，营地、城堡、和平地点及纪念碑与实际作战地域分开。没有根据猜测绘制行军路线或方阵。伊普尔约1610所制1383围城图不作为1383同期测绘。
