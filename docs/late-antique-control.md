# 四至五世纪关键事件的地点归属对照

这组功能补充395、410、439、442、476、493年。每组提供事件前后切换、政治背景颜色、城市与组成地域入口、核查来源及分享参数。

| 年份 | 对照问题 | 地图表达 |
| --- | --- | --- |
| 395 | 王朝内的两部宫廷继承 | 西部与东方城市分别着色；此前已有共治皇帝 |
| 410 | 罗马被劫掠是否等于永久换国 | 罗马的政治背景保持西部，事件状态改变 |
| 439 | 迦太基何时易手 | 城市从西部转入汪达尔王权 |
| 442 | 控制和和约承认是否同一回事 | 迦太基保持汪达尔颜色，和约状态改变 |
| 476 | 意大利变化是否同时结束所有西部政权 | 奥多亚克、尼波斯、东方宫廷分别显示 |
| 493 | 拉文纳交接是否表示所有意大利城市同时易手 | 拉文纳对照交接；其他意大利城市的战前控制标为待核 |

## 使用

- 进入年代面板，在“关键年份：政权变化对照”选择年份。
- 在面板或地图状态卡切换事件前后。地图点和图例同步改变。
- 点击城市进入年表；对照框单独保留事件前后说明，全年年表不冒充具体事件发生前的状态。
- 点击“查看组成地域”继续查当地城市、居民及语言背景。
- 点击“查看百年疆界参考”恢复原来的300、400、500年参考轮廓。该层仍显示轮廓实际年代。

分享参数：`?year=476&view=control&moment=before`。`view=reference`表示查看百年参考疆界。没有收录事件的年份不会套用最近事件的城市归属，也不生成前后状态。

## 精度与来源

这是**地点政治背景层，没有新增精确疆界多边形**。有资料才能确认城市交接，并不足以推定周边每一段领土边缘。未着色地点不表示无人居住或没有政权。圆圈和镜头范围都不表示领土面积，也不用于居民比例统计。

395年保留两部宫廷的罗马共同政治背景；410年不把劫掠队伍画成永久国家；439—442年不把现代突尼斯或整个北非判作和约范围；476年保留达尔马提亚的尼波斯；493年不把最后的拉文纳交接时间强行套到所有城市。

史实沿用课程阅读索引，并通过罗马皇帝学术百科、古典学学会研究、大都会博物馆、剑桥大学出版社及普罗柯比史料核查。来源按各组链接提供。普罗柯比是较晚叙事，不能单凭其叙述复原精确国界。

逐年领土多边形、前线及条约界线仍待有比例尺和可核查出处的地图资料；本层不能宣称这些工作已经完成。
