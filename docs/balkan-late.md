# 1360—1453巴尔干：称号、地方治理和征服的不同时间

沿用27个明确时点，加入塞尔维亚摩拉瓦—多瑙河、波斯尼亚、特尔诺沃与维丁四块固定阅读核心，阶段共33地域。新增11个古今地点、327条单年城市/事件卡；复用科索沃、尼科波利斯与瓦尔纳原点，移除原焦点循环3条重复卡。记录数表示检索覆盖，不是327次独立人口调查。

帝号、knez王公、despot拜占庭高级称号、ban班和波斯尼亚王号各自解释。1377波斯尼亚王号含继承主张但不覆盖全部塞尔维亚。1409摩拉瓦分治、1410复并；1389摄政与后续附庸；1427贝尔格莱德归匈牙利与新建斯梅代雷沃；1439失守、新布尔多坚持到1441、1444恢复与1453仍有地方领国，不能压成同一征服日。波斯尼亚1420回位、1435年末在匈牙利及反王关系保留。

特尔诺沃1393陷落、希什曼1395死亡、维丁1396前后征服分别记录。康斯坦丁二世的称号和可能的地方治理存在争议，1422去世不继续列为在位者。1402—1410奥斯曼诸子争位时，具体城池驻军未核齐；不填统一实控。1444穆罕默德二世为名义苏丹、穆拉德二世领军，附庸、统帅和地方官不是同一职衔。

## 空间与证据范围

新几何为原创编辑坐标，经公有领域Natural Earth现代陆地裁切。与此前1432几何逐一比对保留内容不变，另增108条。四核心在各年保持相同包络以便定位，不是逐年国界、王室领地、行政区或族群边界。新增维丁核心仅作编辑裁切以避免与摩拉瓦核心重叠，不宣称该接缝为历史国界。

克鲁舍瓦茨、斯梅代雷沃、维索科、博博瓦茨、亚伊采、特尔诺沃、维丁落在相应核心。贝尔格莱德、新布尔多、普里兹伦、杜布罗夫尼克及瓦尔纳为核心以外比较点。链接和商人联系不证明行政隶属。坐标均为约略代表点；亚伊采UNESCO预备名录的坐标存在不一致，本图用现代城市的约略位置，不照抄有误DMS。博博瓦茨是遗址，维索科山上堡与山下商镇分开；现存建筑后期增建不回填到较早年。斯梅代雷沃从1381节点起给旧聚落位置背景，不声称本轮独立核定其最早见载；亚伊采从1396节点起为检索范围，也不据此声称其准确建城年。

新布尔多用正教/天主教教堂、矿工/商人和1412法的留存抄本提供有限线索。塞尔维亚科学院2019页面涉及现代争议，本图仅采用档案、抄本和铭文事实，不引入政治论断或民族多数推断。波斯尼亚共享石碑墓葬来自UNESCO；1404赫瓦尔抄本的语言/字母来自博洛尼亚大学馆藏目录PDF96页，不提前称为较晚草写体。特尔诺沃四福音书1355—1356，抄写地点可能但未证实；维丁1360题记与现存可能15世纪初的抄本分开。均不能外推全体居民母语、祖源及比例。
