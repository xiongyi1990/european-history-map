# 埃及的三段阅读入口：公元 300—500 年

新增佩卢西乌姆（今法拉马遗址）与俄克喜林库斯（今巴赫纳萨），共七段城市资料。三角洲—中段河谷—阿斯旺可逐级查看古今位置、政治背景、居民活动、书写语言及邻近地点。

## 阅读顺序

1. `?year=395&region=egypt-delta`：北部三角洲，西侧亚历山大里亚，东侧佩卢西乌姆通往西奈与巴勒斯坦方向。
2. `?year=395&region=egypt-middle`：三角洲以南的河谷城市入口。俄克喜林库斯在主河道以西、优素福水道旁。
3. `?year=395&region=egypt-upper`：向南上溯至阿斯旺与菲莱边区。

“下”在北、“上”在南，跟随河流方向。中埃及是阅读地理，不是一个新增政权，也不是阿卡迪亚行省多边形。镜头框可重叠，不能作为裁定边界的几何。

## 文书分期

- 315—316 年的 P.Oxy. LXIV 4441：城市维修材料与医生报告。315 年仅开放维修档案背景，316 年起显示医生报告。
- 342 年 1 月 28 日的 P.Oxy. L 3577：省长给俄克喜林库斯两位显要的税务信。写信地是北面的赫拉克利奥波利斯，不将写信地点误标为收信地点。
- P.Oxy. LXIII 4371：四世纪中叶佩卢西乌姆的庭审记录，拉丁文框架与希腊文发言。只有宽泛年代，不虚构 350 年精确事件；395 年及之后的城市卡片以回顾性证据展示。

上述文书由[牛津纸草项目展览](https://oxyrhynchus.web.ox.ac.uk/millennium-documents)核对。希腊语、拉丁语在具体文书中的用途，不构成全城母语或族群比例统计。出土地、书写地、事件发生地分别记录。

## 范围与来源

- 城市资料仅覆盖 300—500 年，395 年前后政治称谓分开。
- 佩卢西乌姆地形、港口与历史入口据[发掘负责人报告](https://archive.archaeology.org/online/features/pelusium/)。遗址的晚六世纪要塞没有回填到四世纪。
- 俄克喜林库斯的位置与纸草背景据[牛津项目介绍](https://oxyrhynchus.web.ox.ac.uk/introduction)。没有把后世赛马场、阿拉伯征服等细节提前显示。
