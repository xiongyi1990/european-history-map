# 拜扎凯纳：300—500 年阅读地域

入口：`?year=395&region=byzacena`，也可从 395 年意大利大区的阿非利加目录进入。两座新增城市：哈德鲁梅图姆（今苏塞）、提斯德鲁斯（今杰姆）。地域、城市详情、古今名搜索及城市返回地域统一连接。五段城市记录合计 10 条，覆盖 300—500 年；此范围只是本次收录范围，不是城市存续起止。

## 时段与空间

300—394：罗马北非；395—428：西部朝廷背景；429—438：战争、各城交接待核；439—441：征服背景与和约分开；442—500：汪达尔王国框架。地域内海岸与内陆不同，镜头框由编辑为阅读设置，不是逐省疆界，也不作为族群或语言边界。

居民、语言分为城市有据事实与北非地域背景。杰姆遗存不证明四五世纪仍维持三世纪人口规模；未补造地方人口比例。语言旁证沿用既有北非来源（奥古斯丁书信 209 为约 423 年区域旁证，不是本城各年语言普查）。课程第 133 讲沿用已核对的关联阅读页码 1125—1129，只作为汪达尔背景入口，不宣称课程逐一介绍这两城。

验证覆盖所有 201 个年份的城市记录唯一性、资料引用、地域返回、时代边界、行政目录，以及实际浏览器的搜索与年份操作。

事件对照年份进入地域详情时，现在保留该地域的城市定位点和选中地域标签。城市若不在对照证据名单中，不赋予对照政权颜色或前后归属；提示区说明区别，仍隐藏邻近百年疆界。
