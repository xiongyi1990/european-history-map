# 1360—1453罗斯：四个核心、王公与地方制度

本批不新增年份。在既有27个明确时点新增莫斯科—弗拉基米尔、特维尔、诺夫哥罗德和普斯科夫四块阅读核心，阶段增至29地域。新增8个定位点，复用已有moscow；239条单年城市/事件卡把当年王权背景与有限的制度、文书和物质证据连接。记录数不代表239次独立人口调查或逐年实控地图。

## 政治状态的变化

- 1360莫斯科的德米特里·伊凡诺维奇与苏兹达尔的德米特里·康斯坦丁诺维奇是两人；弗拉基米尔册封不能提前归莫斯科。1362—1363竞争后才进入下一状态。
- 1375特维尔承认莫斯科优先没有消灭本地政权。特维尔1365/1366、1424/1425纪年差异不被用来编造本清单以外的交接日。
- 1380库利科沃击败马麦一方，1381不能提前写1382已发生。1382劫掠、随后纳贡/人质和1389汗使主持即位说明权利层次。
- 1397德维纳暂转莫斯科、1398归还，分别落实1396/1397/1399节点；北方边区未画入核心。共和国未因一次边区变化被整体吞并。
- 1431赴汗廷与1432裁决、1433/1434/1446王位中断及1450/1453伊凡共治分别说明。舍米亚卡是流亡争位者，不直接写成诺夫哥罗德唯一统治者。
- 普斯科夫单列地方政治共同体，逐年王公姓名仍缺。1348协议的纪年与性质有讨论；不能把文化教会联系画成诺夫哥罗德直辖，也不能把1397序言等于现存法典一次完成。

## 地理、居民及语言

全部几何为原创编辑包络，经Natural Earth现代陆地裁切；不是历史边界描摹。保持原1324几何内容不变，新增四核心×27年=108；库利科沃、梁赞、基辅及北方边缘不在这些核心内。托尔若克只列诺夫哥罗德关联，不因邻近特维尔变更归属。现代地点代表坐标不复原城界、驻军或战场阵位。

居民不填祖源百分比。特维尔博物馆的工匠、钱币和印章、诺夫哥罗德商院、鲁萨家书和字母练习给出职业、家户与书写的具体线索。进口器物不证明对应族群常住；商院的特权不构成汉萨领土；城市共和制不等于现代普选民主。

语言证据保留古文与译文、估年和地层断代。诺夫哥罗德1号约1380—1400，莫斯科1号暂定1410—1420且可前后移动，鲁萨2号约1410—1420且有更晚地层判断；不压成某个单年书信。1392尼布尔和约的古俄文/中古低地德语传本只说明跨语外交，不说明全城双语比例。特维尔当期具体语言文书尚缺。

修道院1408火毁、1412木教堂、1422石教堂分期；16世纪石墙不能出现在1370年代。弗拉基米尔明确指克利亚济马河上的城市；诺夫哥罗德与下诺夫哥罗德分开。
