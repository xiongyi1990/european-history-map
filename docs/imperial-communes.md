# 1105—1183年：帝国、教皇与意大利城市

15个独立核对的时点：1105、1106、1111、1122、1125、1133、1138、1152、1155、1158、1162、1167、1176、1177、1183。沿用五个命名阅读地域，不称逐年实控疆界。国王、皇帝、贵族、主教与城市公社分层记录。

## 阅读顺序

- 1105年末父亲被迫退位，1106年父亲去世，1111年儿子亨利五世获帝号；不把三个状态合并。
- 1122年9月23日沃尔姆斯协约：戒指和牧杖所代表的宗教职分，与以权杖授予的世俗权利区别；德意志、意大利及勃艮第程序不同，不是领土割让。
- 1125年洛泰尔为王，1133年在拉特朗获帝号；1138年康拉德三世当选，其终身未加冕为帝。
- 1152年巴巴罗萨为王，1155年帝号；1158年龙卡利亚会议及权利争议，1162年米兰投降和破坏，1167年城市重建及同盟发展。
- 1176年5月29日战役、1177年与教皇和解及城市六年停战、1183年6月25日正式城市和约分别阅读。自治与对皇帝的义务可以同时存在。

## 顾衡课程与独立核验

已阅读用户PDF物理页1427—1429、1442—1446。第167讲提供叙任权背景，第169讲连接北意大利、王朝与城市。课程概括叙述中的1177年安排，不代替1183年城市正式和约；前者与六年停战、后者的权利确认分开。

1122年程序据林茨大学刊载的两份文书译文及Treccani协约条目核验；不采用“皇帝碰一下牧杖即可”的简化场景。亨利五世、洛泰尔、康拉德三世、腓特烈一世据德国传记年表；法兰西各王分别据王室文书数据库和BnF，未沿用1100年的旧君主。城市定位及事件另据沃尔姆斯、莱尼亚诺和康斯坦茨官方城市资料。来源URL见imperial-communes-sources.ts。

## 地点与空间边界

新增沃尔姆斯、莱尼亚诺、康斯坦茨与威尼斯四个城市代表点，坐标为编辑性概略定位、保留两位小数；不称精确签署地点或考古战场。补11条单年城市说明，包含罗马1111/1133/1155、米兰1158/1162/1167/1183、威尼斯1177及三个新点的对应事件。

城市关联不自动等于皇帝直辖。卡诺莎、威尼斯、米兰与莱尼亚诺不因出现在意大利地域卡上而推断皇帝直接拥有。康斯坦茨是1183年签约地，不是新增伦巴第领土。5块阅读包络没有新增教皇或城市实控分区，尚未覆盖同时期整个欧洲和城市所有辖地。

居民条目解释政治身份与地方社会，不制造人口比例或族群、语言边界。相邻未核对年份不借用本批状态。
