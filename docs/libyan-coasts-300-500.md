# 利比亚沿海：两组阅读地域（300—500 年）

2026-10-10。保留已发布的 tripolitania400、cyrenaica400 标识，把统一阅读入口向前接通到 300 年；底层 400 年快照函数不改。行政目录与上层行政大区分别直达西部的黎波里塔尼亚、东方昔兰尼加。新增萨布拉塔及昔兰尼海港阿波罗尼亚，两城各六段，共十二条记录。原利比亚链接继续作总览。

## 分期及限制

城市记录分 300—364、365—394、395—428、429—438、439—441、442—500。萨布拉塔地震后说明只从 365 年出现；未将每座沿海城市的灾损强度一概而论。政治背景按东西分别处理，不把 439 年迦太基易手等同于昔兰尼加易手，也不编造西部各城的交接年。365 年等年度标签指年内发生及之后的背景，无法区别同一年中的月日。

镜头范围是阅读窗口，没有新增精确省界或族群面。东西部居民和书写传统单独说明，碑铭与建筑不能推算全体居民比例。晚期上下利比亚不能解释成现代利比亚国界内部的南北两半。课程仍作全图辅助阅读；本批城市的直接证据来自以上来源，不冒称顾衡逐一讲解。
