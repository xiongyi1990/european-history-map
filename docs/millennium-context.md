# 1000 年同期欧洲定位导览

本批把法兰克继承诸国与六个外部方向接入同一个地图：英格兰、伊比利亚、东罗马与保加利亚、基辅罗斯、皮雅斯特波兰、匈牙利。入口为 `?year=1000&view=partitions&context=all`；`context=england/iberia/balkans/rus/poland/hungary` 可分享所选方向。

## 空间表达与范围

- 新增可点击地域定位标签和城市参照，不新增未经核验的国界多边形。相机 bounds 只表示取景窗口。
- 保留中西欧原有色块；六个方向不因留白而被误读为无人或无政权。
- 每卡分开呈现统治者、年代、组成线索、邻国关系、居民/语言、城市与来源。
- 仅适用1000年；切换962、987、1001或现代会清除比较上下文。城市详情返回时保留原比较方向。
- 不声称全欧洲覆盖：斯堪的纳维亚、北非、波希米亚、克罗地亚等仍有待独立展开；英格兰不等于不列颠，科尔多瓦不等于整个半岛。

## 课程与来源核验

以用户PDF物理页码为准，读取第148讲1245—1246页、第156讲1311—1313页、第177讲1513—1514页作为背景。波兰、匈牙利等本卡内容属于独立补充，不伪造课程对应页。

第177讲1514页把克努特英格兰即位写作1014年，并称其杀死埃塞尔雷德。本批按英国王室年表采用1016年，不采用该死因叙述。1000年埃塞尔雷德在位；1013年出奔与1014年复位不能提前套入。

其余来源列于 `millennium-context.ts`：英国王室、Met、国家考古博物馆、普雷斯拉夫考古博物馆、加拿大乌克兰研究所、格涅兹诺和埃斯泰尔戈姆市史。特别保留1000/1001加冕日期差异，区分1000年格涅兹诺会晤与1025年正式加冕，避免把1018年保加利亚征服提前套入。
