# 公元4—5世纪：统一地图覆盖清单

本轮把301—500年的主要阅读空间连在同一地图上。选择年份后，可以查询政治阶段、统治者、组成地域、城市古今名称、居民与语言背景，并进入相关战争路线。**完成的是这一范围的连续阅读入口及核心资料；逐年精确疆界、全部地方史和人口比例仍未完成。**

## 可查范围

| 内容 | 四世纪：301—400年 | 五世纪：401—500年 |
| --- | --- | --- |
| 年份 | 逐年可查，另保留300年专题 | 逐年可查 |
| 核心城市 | 每年70处，记录无重叠 | 每年74处，记录无重叠 |
| 地域 | 前段35组，370年起36组，400年38组 | 保留全部38组，再加10组子地域，共48组 |
| 政治与事件 | 27段政治阶段，50个关键年份 | 65个关键年份及四个宫廷对照 |
| 分阶段战争 | 6个专题、19个阶段 | 8个专题、25个阶段 |

400年为共享节点。合并去重后，两世纪共有114个关键年份、14个战争专题、44个阶段。没有单独事件的年份显示所处阶段；相同地方背景可合并为时段记录，并非为每座城市虚构一百条独立史实。

## 空间组成

- 罗马西部及后继王权：意大利、高卢、伊比利亚、不列颠、海岛、北非与阿尔卑斯。高卢可展开阿基坦、奥弗涅、普罗旺斯、北高卢、萨包迪亚、纳博讷沿岸；伊比利亚可展开加拉埃西亚与塔拉科方向，北非可展开迦太基与努米底亚。
- 罗马东方：色雷斯及巴尔干、希腊与马其顿、小亚细亚、本都与卡帕多西亚、黎凡特、阿拉伯行省、上两河、埃及、克里特、昔兰尼加。西部的黎波里塔尼亚与东方昔兰尼加分别看，现代利比亚不是古代统一政权。
- 萨珊与高加索：泰西封所在阿索里斯坦、帕尔斯、胡齐斯坦可从萨珊展开；亚美尼亚、高加索伊比利亚与高加索阿尔巴尼亚另列。后二者不与西班牙或巴尔干的同名地域混淆。
- 边外与北方：法兰克、阿勒曼尼、哥特、萨尔马提亚相关集团、匈人联盟、黑海北岸博斯普鲁斯、不列颠北部、爱尔兰、北海与斯堪的纳维亚南部。联盟瓦解后仍存在地方社会，不用首领去世解释为全体居民消失。

地域卡保留邻近城市作比较参照；一个城市出现在别处卡片中，不意味着改变主地域或政权归属。组成地域、镜头框、帝国参考疆界和居民身份分别呈现。

## 来源与精度

保留顾衡课程讲次、PDF页码和阅读问题，中文资料独立撰写；公开仓库不包含课程全文或配图。地方补充结合罗马皇帝学术百科、伊朗百科全书、博物馆与遗址资料，以及阿米阿努斯、格雷戈里、约尔达尼斯、普罗柯比和《圣塞维里努斯传》等史料。出处按条目链接，古代作者的传说、数字和偏见不直接当作精确地理事实。

疆界仍使用明确标注年代的300、400、500年快照。中间年份的文字说明随年份变化，借用轮廓不会冒充该年的精确国界。路线表达战区方向与叙事顺序，不是逐日行军道路；尼达奥、卡塔劳努姆及部分撤退路线不确定时，不画猜测战场。居民资料以政治身份、社群、语言和宗教分别说明，没有证据的人口比例不填写。

395、410、439、442、476、493年另提供[事件前后地点归属对照](late-antique-control.md)。在此模式中隐藏百年疆界，用城市点表达政治背景，图例、详情及分享链接随事件前后切换。没有新增精确疆界多边形，也不把劫掠、和约承认和持久征服合为一类变化。

仍需持续补充的主要内容：逐年疆界与实控差异、地方行政改革、更多小城和乡村、道路和贸易、教会网络、人口数量及迁居细节。五世纪北方与高加索主要是地域背景，资料密度低于罗马核心城市，不能称为全部地方年表。
