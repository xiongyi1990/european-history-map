# 毛里塔尼亚三个阅读地域（300—500 年）

2026-10-05。新增廷吉塔纳、凯撒里恩西斯、锡提芬西斯三个阅读地域及廷吉斯（丹吉尔）、毛里塔尼亚凯撒利亚（舍尔沙勒）、锡提菲斯（塞提夫）三座城市。每城五段，共十五条日期记录。旧毛里塔尼亚链接继续作总览；与努米底亚的城市详情互相连接。

## 时间与空间说明

300—394、395—428、429—438、439—441、442—500 是阅读背景分段，不是三城在首年易主的证明。晚期名册不代表 395 年同一天的完整实际管辖，更不能原样延长到 500 年。三组窗口只帮助定位，不新增主权或族群多边形。父地域向东扩展至塞提夫；提姆加德从其城市列表移除，保留在努米底亚。行政目录内廷吉塔纳归西班牙组，另两组归阿非利加；沃鲁比利斯以撤军后城市作地理对照。

三城均支持古今地名搜索、年份保持与返回所在地域；居民、语言表述分别注明地区背景或城市证据，不给出未经史料支持的人口比例。顾衡课程继续作为全图阅读辅助，本批新增地点未冒称课程逐一讲解。
