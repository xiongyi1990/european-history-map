# 1360—1453北欧：共同君主、三套制度与城市例外

在原26时点增加丹麦、挪威、瑞典三个阅读核心，并显式加入1397年年底节点，共27时点/25地域。1397的法英、帝国、波希米亚、苏格兰、波兰、立陶宛、匈牙利、海峡、西西里/那不勒斯、勃艮第/佛兰德与伊比利亚君主，按已有独立来源的任期明确列入，未复制邻年记录或插值前线。

几何为原创编辑包络，经Natural Earth现代陆地裁切。丹麦有日德兰、菲英/西兰及斯堪尼亚核心；挪威只画西海岸/南部至尼达罗斯；瑞典只画大陆中南部。芬兰、哥特兰及海外岛屿以点位/文字联系，未按照现代国家和行政区全域填色。运行python -X utf8 scripts/build-frankish-successors.py检查有效性、非重叠和代表点；原1221几何内容不变。商站不产生一个汉萨国家色块。

关键区别：1360/1364挪威父子分治；奥拉夫1380继承/1381拥戴，同一人在丹麦叫奥卢夫二世；埃里克挪威1389、丹麦瑞典1396承认与1397共同加冕分开；玛格丽特主导实政至1412。1397文书法律性质有研究分歧，不等于签成一部统一国家宪法。1389战胜后斯德哥尔摩仍须到1398才交接。1435卡尔为军政高官，1439为摄政，1448才是国王。

1439丹麦废黜与挪威不同步。1440挪威记为名义任期/过渡：SNL克里斯托弗详文、埃里克详文及王室年表存在1440/1441/1442切换节奏差别，不伪造单日交接。克里斯托弗1440丹麦、1441瑞典、1442挪威选立/拥戴，瑞典1441乌普萨拉加冕、挪威1442奥斯陆加冕、丹麦1443里伯加冕分别说明。1450年底丹挪克里斯蒂安与瑞典卡尔已不是同一位君主。

哥特兰1398—1408条顿骑士团占领、埃里克失瑞典王号后继续控制岛屿、1449瑞典撤军及1450/1453丹麦实控分别记录；早期未核到逐日状态的点保留说明。挪威奥克尼/设得兰抵押在1468/1469，1453不提前归苏格兰；格陵兰等不同纳贡/属地关系不画为整个现代地块的稳定实控。

城市与社群：布吕根是卑尔根港区，德意志商人和鱼干贸易的证据不推导全挪威人口比例；斯德哥尔摩有吕贝克商人特许；哥本哈根1417主教座控制变化；今乌普萨拉与旧乌普萨拉分开、1435教堂祝圣不等于此前没有主教座；尼达罗斯与现代特隆赫姆是同城不同名称。卡尔马城堡谈判与当时城镇教堂加冕不混为一处，现存较晚大教堂不是1397仪式定位。战役只标约略地域，未复原精确部队路线。
