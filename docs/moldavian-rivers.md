# 摩尔达维亚河海通道：城市、驻军与贸易

2026-11-19续批。新增白堡、基利亚、霍京、利沃夫4处地点：27个既有时点共108条城市资料；另有1408、1436、1448、1465、1484五个地点证据年、10条专条，合计118条。五年只增加明确的地方证据，没有借用邻年全欧洲状态。44处阅读核心及全部1837个几何记录保持原内容；只扩大摩尔达维亚定位视野以容纳块外比较城。

## 初学者先区分

- 霍京是德涅斯特河沿线的内陆河堡，白堡在该河河口潟湖旁；基利亚在多瑙河支汊。德涅斯特河与课程提及的第聂伯河不是同一条河。
- 利沃夫与苏恰瓦由贸易相连，不因此同属一国。新城市链接均为比较点，不自动取得摩尔达维亚核心的政权颜色。
- 基利亚采用两岸之间的编辑性河段代表点。Holocene2021主张北岸历史中心，其他研究讨论南侧堡与迁置；不能因现代Chilia Veche带“旧”字就认定中世纪堡垒的精确位置，也没有将争议地点额外造为两座已核古城。
- 1412分割计划没有实施；1436霍京承诺与是否交付有争议。1450霍京马诺伊尔支持中央王公的竞争者；1453基利亚的匈牙利驻军与瓦拉几亚税关行政分开，不能复制苏恰瓦标签。
- 白堡1440铭文在11月10日，主节点只定下半年，保留其与节点相对时间的不确定性。1443—1447、1449和1453地方官记录也不冒充每年新名册。
- 1462攻取失败、1465取得基利亚、1479新堡分开；1484基利亚7月与白堡8月先后失守，不能让苏恰瓦也自动同步改属。

## 验证与后续

新增测试覆盖所有链接、五个地点年份与无全欧框架的分离、官员与中央王公的差异、港城位置争议、铭文/建筑时点及单点详情返回。原1837几何记录按解析内容逐项保持不变，未改年度疆界。

可用浏览器尝试创建了本次专用验收页，随后读取页面状态超时并重置连接；没有取得可检查画面，视觉、移动端与控制台验收仍待补。开发预览会在收尾停止，站点更新仍须通过测试、构建、GitHub和Sites发布及完整线上资源校验。

下一批转1453—1517更宽的政治格局，并保留阿尔巴尼亚其他地方权力、港口早期驻军、完整河海通道边界和家庭语言的缺口。所有宽域审核仍partial，新增标题或单点年份不构成全欧洲完成。

本批验证实绩：23项数据/地图检查与4项应用交互检查通过，共27项唯一检查；TypeScript与生产构建通过，仅保留既有大体积chunk提示。覆盖审计618目标年、6817条时段记录、0引用问题，全部审核未完成。初次断言措辞和kind类型检查已修正；相关检查重跑通过。
