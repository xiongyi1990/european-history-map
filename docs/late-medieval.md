# 1285—1356：战争、教廷与选帝

本批21个明确时点：1285、1291、1295、1297、1302、1303、1306、1308、1309、1312、1314、1317、1322、1327、1328、1337、1346、1347、1348、1355、1356。接在1190—1282专题后，在同一地图切换，不外推相邻年份。

在既有八个地域基础上加入苏格兰大陆核心、佛兰德城市地域、波希米亚核心、波尔多—巴约讷加斯科涅核心。佛兰德、加斯科涅从原概览包络中划出以便阅读，不能解释为这些地域在1285年突然独立。几何为原创编辑性阅读包络，裁切现代陆地；不是复制史图，也不是逐年实控国界。苏格兰岛屿、波希米亚全部王冠领地、各城堡和地方阵营分界尚未复原。

新增16个地点及204条单年城市记录。战役地域使用近似代表点，普瓦捷1356在城东南，与732图尔—普瓦捷事件分开；黑太子与爱德华三世分开。1356七位选帝侯分别连接代表地点，海德堡、维滕贝格、勃兰登堡城只是地方方向参照，不是假定选侯本人当年就在该城，也不是七块覆盖帝国的省。

## 时间与地理审核

- 1291取年底：鲁道夫已去世，阿道夫1292才当选。1295西西里腓特烈为年底领主，1296才加冕。1321以后父子共治不省略彼得。
- 1308选举、1309王冠、1312拉特朗帝冠分别说明。1327路易仍无帝号，1328由罗马城市代表主持帝冠；1346查理在波恩加冕为竞争国王，1348仍不是皇帝，1355才获帝号。
- 1309阿维尼翁迁驻、1348购城分开。课程p1600的地理概括不能写作今天意大利境内；当时城市领有也不能由现代法国国界推断。
- 1314取12月：班诺克本已发生，法王已为路易十世。苏格兰战争胜利与1328和约分开。1346苏格兰大卫被俘后仍有国王和监国，不涂成全国并入英格兰。
- 1347取11月：加来已投降，路易四世已去世。1348乔安娜返国时仍有城堡被匈牙利军占据；回城不表示重掌全部王国。
- 1355取11月底：岛上路易已去世、腓特烈四世已在墨西拿受效忠。1354巴勒莫转向安茹一方，与墨西拿等阿拉贡支持区分开，不能称作整岛统一实控。1355—1356大陆注明乔安娜、塔兰托路易共同王权。
- 1356取12月底：普瓦捷已发生、金玺诏书梅斯补充阶段已完成。法王被俘与王太子治理分开，不提前称查理五世。

## 课程与独立核验

实际阅读第186讲PDF1587、第187讲1599—1600、第194讲1654—1655及1660、第195讲1661及1665。它们提供教廷、英法大陆封地和跨海贸易线索；没有假称苏格兰或金玺诏书已找到直接课程页。

帝国与西西里按NDB、HLS、Treccani独立条目，金玺诏书按耶鲁Avalon原始文书译本，1348布拉格按大学创立文书；英苏按王室年表、HES战场名录与NRS档案说明，佛兰德按遗产局城市研究与学术百科；加斯科涅使用Gascon Rolls文书项目，法国王号以BnF与国家档案文书目录交叉核对。网站可能限制静态获取，目录不能单独作为全文事件细节的证据。链接见late-medieval-sources.ts。
