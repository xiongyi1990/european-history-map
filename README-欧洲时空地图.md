# 欧洲时空地图

产品方向更新：2026-09-10，以用户最新说明为准。

## 定位

面向任何欧洲史、现代欧洲读物的通用地理查询工具。用户打开同一张 3D 地图，按时间、地点、政权或事件查询，理解某个时代的空间关系。书籍和课程作为资料来源及可选阅读入口，不作为地图的数据分区，也不要求按章节制作或拼接。

## 核心使用方式

1. 输入年份或选择时代，查看该时段有资料支持的政权、名称、疆界和重要城市。
2. 搜索古今地名及别名，定位地点，并查看名称和归属的时间变化。
3. 查看山脉、平原、高原、河流、海洋和海峡，旋转、缩放，理解地理条件。
4. 按需打开族群、语言、文化分布；这些分布单独记录，允许重叠，不从政权疆界推断。
5. 选择重大事件或战役，查看发生地点、阶段路线和地形关系。
6. 在历史与现代视图之间对照；现代资料注明更新日期。

## 统一的数据与表现方式

- 地点、政权、边界、人口群体、事件使用稳定标识；所有地理数据保存统一经纬度。
- 名称、统治关系、边界和分布各自记录适用时间、资料来源、确定程度，不能只给整个国家一个永久标签。
- 年份输入可以连续，资料精度必须如实呈现：明确区分所选年份、所用史料年份和有效时段；缺失时显示未收录或可参考的邻近年代，不把邻近快照当作当年事实，也不自动把两次疆界平滑插值成史实。
- 史前部分以遗址、文化和迁徙证据表达；现代地形只是参考底图，未经重建的古海岸线不宣称精确。
- 网站作为日常查询和分享入口；Blender 用于地形、美术资产及高质量场景渲染。地名、时间筛选、疆界和路线由共同的数据驱动。
- 现有课程场景保留为已有素材，不继续把独立章节文件作为主线。

## 使用与验证

本机启动：在本项目目录运行 `npm run dev -- --port 5180`，浏览器打开 `http://127.0.0.1:5180/`。地址可以记录年份、地点与战役阶段；本机地址无法直接分享给其他设备。公开访问仍需部署。

可试的阅读路径：

1. 输入 `117`：地图保留所选年份，同时明确显示实际参考快照年份。
2. 在顶部搜索框搜索“君士坦丁堡”；输入 `395`，查看与今天伊斯坦布尔的位置对应，以及这个特定时点的归属说明。
3. 进入“战役路线”，选择汉尼拔，逐阶段查看跨越比利牛斯山、罗讷河及阿尔卑斯山的方向。
4. 切换“现代对照”，或关闭疆界专注观察地形。

`npm test` 验证日期、时间查询与旧专题兼容性；`npm run build` 检查类型并生成站点。`python scripts/audit-europe-assets.py` 检查地理坐标、图块完整性和文件哈希，结果保存在 `artifacts/europe-atlas/asset-verification.json`。这些技术检查不等于历史准确性审定。

资料版本和许可保存在 `public/europe-reference/manifest.json`、`public/historical-boundaries/manifest.json` 与后者目录的 `LICENSE`。既有历史数据的原始上游提交版本未知，已如实记录；后续考证应替换为可追踪的版本及逐项来源。
